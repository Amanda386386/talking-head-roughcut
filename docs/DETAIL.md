# 口播粗剪（talking-head rough cut）

把单机位口播素材与口播稿对齐校准，自动去重录、删卡壳、清长气口，按原分辨率原码率输出粗剪成片。

## 用法

在对话里说：

> 用 talking-head-roughcut 粗剪这条视频，视频在〈路径〉，文案在〈路径〉。

需要准备：一个视频文件（.mov/.mp4）和一份口播稿（.docx/.txt/.md）。

## 会做什么

- 同一段台词连录多次，只保留最后一次完整录制；前面说一半又重说的，前面那半句整段删掉。
- 剪掉卡壳和 0.5 秒以上的长气口；任何 3 秒以上的静默必剪。
- 句尾语气词（呢/啊/了/的）和「左右」「大概」这类模糊限定词完整保留。
- 切点交替换景别（1.0/1.09），且不剪到字。
- 只做粗剪：不加字幕、花字、调色、BGM、音效。

## 产出

在视频同级生成 `<视频名>_粗剪\`：成片 mp4、`剪点表.csv`、`粗剪报告.md`、`plan.json` 等。

## 限制

- 依赖本机 ffmpeg、ffprobe 和 faster-whisper large-v3 模型，路径在技能目录 `scripts/environment.json` 里配置。
- 只做粗剪；精剪（字幕、特效、配乐）另起流程。
